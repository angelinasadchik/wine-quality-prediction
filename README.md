# Wine Quality Prediction

This project demonstrates a simple machine learning pipeline for predicting wine quality using chemical measurements.

## Dataset

The dataset contains physicochemical properties of wine samples such as:

- acidity
- sugar
- pH
- alcohol content

The task is to predict whether a wine is high quality or not.

## Model

A Random Forest classifier was used.

Steps:

1. Data loading and preprocessing
2. Train-test split
3. Model training
4. Accuracy evaluation

This project was created as a small practice project while studying machine learning.
